## 1. kltEndgameSummary：他们收尾论证的一段话概括

KLT 对 N=8（s∈{0,1}，方反棱柱 X(a_s) 为内点型最优解）的收尾**根本不走
"薄层 ⇒ 逼近最优构型" 的稳定性链**，而是把证书做成**在候选构型处精确取等**，
然后用**离散等号情形分析**收尾。命题结构是一条零 ε 三明治（§2 Steps 1–5,
p6–9；§4–6）：
Ê_s(Y) ≥ E_{H_s}(Y) ≥ E_{H_s}(X(a_s)) = Ê_s(X(a_s))。
第一层（Step 2, §4.1 引理 4.1, p12）：对候选的 4 个内积节点
A,B,C,D 做**值＋一阶导数的 Hermite 插值**（在 −1 处再加 0–4 阶共 5 个条
件，合 13 条、deg ≤ 12），由 φ_s^{(13)}>0 的余项公式
φ_s(t)−H_s(t) = φ_s^{(13)}(ξ)/13!·(t+1)^5∏(t−α)^2 > 0（节点外严格），
得**全局单一**多项式 minorant，且等号集恰为 {−1,A,B,C,D}——E_{H_s}(X(a_s))
= Ê_s(X(a_s)) **精确成立，两点层缺口为零**。第二层（Step 3, §4.2–4.3,
p13；命题 4.3）：Cohn–Woo 三点半定框架，把 12(E_{H_s}(Y)−e_s) 写成
**非负项之和**的精确多项式恒等式 (4.5)：矩阵容器项 6Σ⟨F_k, M_k(Y)⟩
（引理 4.2：M_k(Y) ≽ 0 对任意构型成立，复坐标 ζ_y 外积和证明）＋
SOS 项 Σ Sym(g_j z_j^T W_j z_j)（g_j∈{1,1−u²} 域乘子）。
Step 4（§6, p16–18）核验恒等式精确成立：对数情形 a_0=(2√58−13)/7 代数
精确、逐单项式五分量（1,L₂,L_A,L_C,L_D）核零；Coulomb 情形 a_1 只有区间
隔离 (6.2)，用 **99×99 精确 Newton 修正**（§6.2：w = w_0+z, z=M^{−1}r，
‖z‖_∞ ≤ 2^{−38}）把恒等式修到在真值 a_1 处精确成立，再用盒上区间论证
（引理 6.3：‖PBP^T−I‖_∞ ≤ δ<1 ⇒ B≻0）保正性存活。Step 5（§5, p14–16）
等号情形：取等 ⇒ 每个非负项分别为零 ⇒（i）全部非对角内积落入节点集
{−1,A,B,C,D}（−1 被节点条件 α+β≠0 排除）；（ii）对数情形用命题 5.1——
ker F_0 = Rm*（k=0 矩阵容器的秩条件）⇒ 每顶点幂和 ∑_z(y·z)^i, i=0..3
与候选相等 ⇒ Vandermonde ⇒ 逐顶点邻型计数 #A=2,#B=1,#C=2,#D=2 ＋质心为零
＋严格正定 SOS 项的禁三角条件（两 A 边 ⇒ 第三边 B）⇒ A-图 = 两个四圈 ⇒
两个正方形＋对心＋C/D 型强制 π/4 相对旋转 ⇒ X(a_0)；（iii）Coulomb 情形用
命题 5.2——64 个节点三元组 Gram 行列式全非零 ⇒ 任三顶点是 R³ 基，第四顶点
由其三个内积完全决定（扩展多项式 Δ (5.2) 判据），4096 种扩展情形中 105 种
由候选顶点实现、3991 种 Δ≠0 排除 ⇒ 首三顶点 Gram 匹配给正交映射 ⇒ 整构型
≅ X(a_1)。**整个收尾没有任何 ε、任何管半径、任何 Taylor 余项**。对大 s
（定理 1.2, §7, p19–22）才用两段式解析路线：Step 6 定位（能量亚水平集 ⇒
所有点对距² ≥ τ·28^{−2/s}＋打包唯一性紧性 ⇒ 近 P；再由引理 7.1 接触图
无穷小刚性——16 条接触边微分公共核恰为 3 维旋转、带权重 1 与 κ=1+1/√2 的
严格正自应力，Fourier 模分析——得 (7.3) min_e f_e(z) ≤ τ−c‖z‖，合并得
‖z‖ ≤ K/(2p)）；Step 7 凸性（§7.3 旋转横截坐标 χ_P(z)=Exp_P(z)＋IFT；
§7.4 分解 D²E = 正项 p(p+1)Σf_e^{−p−2}(Df_e)² − 负项 pΣf_e^{−p−1}D²f_e，
正项用刚性下界 Σ_{contact}(Df_e(z)[v])² ≥ λ‖v‖²（管上全域），负项用管上
一致界 |f_e(z)−f_e(0)| ≤ L‖z‖、|D²f_e(z)[v,v]| ≤ M‖v‖²，得 (7.5) 管上
严格凸 ⇒ 唯一驻点 = X(a_s)）。注记 7.2（p22）：仓库里 s≥0 全程版为
0≤s≤124 区间覆盖＋精确修正＋一致正性、s≥124 逐环排除＋门限处 Hessian＋
单调性延拓。§1.3（p4）强调"计算机辅助部分的 Lean 验证是本文主要新颖点
之一"；§6.5（p19）：证书用纯标准库 Python verify.py 核验，Lean 侧
Showcase_WithProofs.lean + Checks/Axioms.lean（仅 propext/Classical.choice/
Quot.sound）。

一句话：**KLT 的收尾 = 节点 Hermite 插值让两点层在候选处精确取等 ＋
三点 SOS–矩阵容器恒等式让三点层精确取等 ＋（区间参数上的）精确修正与盒
正性 ＋ 等号情形的"内积入节点集 → 矩/Vandermonde 邻型计数或 Gram 有限
枚举 → 重构构型"离散收尾**；稳定性链（定位＋刚性＋凸性）只在大 s 情形
作为多项式路线不可用时的替代品出现——而且那条链的每个环节（横截坐标、
刚性 λ、一致 D²f 界、Hessian 分解下界）都是显式常数、可直接搬。
